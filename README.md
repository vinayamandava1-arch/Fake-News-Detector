# AI-Based Fake News Detection System

## 📌 Problem Statement
Misinformation spreads quickly through online news and social media, making it hard for students to differentiate between reliable and fake information. This project develops an AI-based solution that analyzes news articles, assesses credibility, and provides concise summaries to prevent the spread of false information.

## 🎯 Objective
To build a machine learning model that detects fake news articles using Natural Language Processing techniques and deploy it as a web application using Streamlit.

## 🛠 Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit
- TF-IDF Vectorization
- Machine Learning Classification Model

## 📊 Model Performance
- Accuracy: 98%
- Evaluated using Confusion Matrix and Classification Report

## 🚀 Features
- Fake/Real News Prediction
- Credibility Score
- Fake News Probability Meter
- Article Summary Generator
- User-Friendly Web Interface

## ▶ How to Run the Project

1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py

## 🔮 Future Scope
- Train on multi-domain datasets (Indian, Business, Sports, Health)
- Integrate real-time fact-check APIs
- Deploy as a cloud-based application
